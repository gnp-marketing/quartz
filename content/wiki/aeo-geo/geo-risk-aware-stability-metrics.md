# 風險感知穩定性指標

**Summary**: IF-GEO 論文提出的三個新 GEO 評估指標，專門量化跨查詢的穩定性和安全性：WCP（最差查詢表現）、DR（下行風險）、WTR（勝平率）。彌補傳統「均值」指標掩蓋尾部退步的缺陷。

**Sources**: IF-GEO - Conflict-Aware Instruction Fusion for Multi-Query Generative Engine Optimization.pdf（Zhou et al., USTC, arXiv:2601.13938v1, 2026-01-20）

**Last updated**: 2026-04-16

---

## 為什麼均值指標不夠

傳統 GEO 評估報告的是**平均增益** E[Δv]，這掩蓋了兩個問題：

1. **尾部退步**：平均可能很好，但某些查詢可能大幅退步——均值無法捕捉
2. **混淆上下行波動**：高方差可能是因為某些查詢大幅進步（好事）或某些查詢大幅退步（壞事），方差 VAR 無法區分

**示例**：

| 查詢 | 方法 A 增益 | 方法 B 增益 |
|------|-----------|-----------|
| q1 | +0.20 | +0.30 |
| q2 | +0.20 | +0.10 |
| q3 | +0.20 | +0.30 |
| q4 | +0.20 | −0.10 |
| 均值 | +0.20 | **+0.15**（看似更差）|
| WTR | 100% | **75%** |
| WCP | +0.20 | **−0.10** |

從均值看方法 A 更好，但方法 B 有 3 個查詢增益更高；方法 A 雖均值高，卻可能讓某個重要查詢退步。

## 三個風險感知指標

### WCP：Worst-Case Performance（最差查詢表現）

**定義**：
```
WCP = min_{i=1..m} Δv_i
```

**解釋**：m 個查詢中增益最小的那個。若 WCP = −0.05，表示至少有一個查詢的可見度因為優化而下降了 0.05。

**用途**：建立安全下界（safety lower bound），確保沒有查詢因優化而大幅受損。

**目標**：越高越好（WCP↑），理想狀態是 WCP ≥ 0（所有查詢至少不退步）。

**實驗對比**（GPT-4o-mini，客觀指標）：

| 方法 | WCP |
|------|-----|
| Unique Words（最差） | −0.1316 |
| Auto-GEO | −0.0511 |
| **IF-GEO** | **−0.0090** |
| 理想值 | 0.0000 |

---

### DR：Downside Risk（下行風險）

**定義**：
```
DR = (1/m) × Σ_i [min(0, Δv_i)]²
```

**解釋**：只對**負增益**的查詢計算平方均值。正增益完全忽略。這區分了「高方差因為有查詢大幅進步」（好事）和「高方差因為有查詢大幅退步」（壞事）。

**數學性質**：
- DR = 0 → 所有查詢均無退步（理想）
- DR > 0 → 存在退步的查詢，值越大退步越嚴重
- 對大退步的懲罰比小退步更重（平方）

**用途**：量化有害的下行波動。比 VAR（方差）更有意義，因為 VAR 把進步也計入不穩定。

**目標**：越低越好（DR↓）。

**實驗對比**（GPT-4o-mini，客觀指標）：

| 方法 | DR |
|------|-----|
| Unique Words（最差） | 0.0095 |
| Cite Sources（GEO 啟發式最佳） | 0.0044 |
| Auto-GEO | 0.0043 |
| **IF-GEO** | **0.0023** |

---

### WTR：Win-Tie Rate（勝平率）

**定義**：
```
WTR = (1/m) × Σ_i I(Δv_i ≥ 0)
```

**解釋**：增益大於等於零的查詢比例。代表「優化至少不讓這個查詢變差」的覆蓋率。

**用途**：作為 Pareto 最優的代理指標——衡量優化是否在不傷害任何查詢的前提下提升整體。

**目標**：越高越好（WTR↑），100% = 所有查詢均無退步。

**實驗對比**（GPT-4o-mini，客觀指標）：

| 方法 | WTR |
|------|-----|
| Statistics Addition | 72.58% |
| Auto-GEO | 73.56% |
| **IF-GEO** | **80.50%** |

## 四個指標的整體視角

| 指標 | 目標 | 衡量的問題 | 缺陷 |
|------|------|----------|------|
| **Mean（均值）** | 最大化 | 平均效果 | 掩蓋尾部退步 |
| **VAR（方差）** | 最小化 | 整體波動 | 無法區分上下行波動 |
| **WCP** | 最大化 | 最差查詢安全下界 | 只看最差一個，可能受噪聲影響 |
| **DR** | 最小化 | 負面波動的嚴重程度 | 不反映退步的頻率 |
| **WTR** | 最大化 | 非退步查詢的覆蓋率 | 只看方向（>0），不看幅度 |

完整評估建議同時報告全部五個指標。

---

## 注意：高 VAR ≠ 不穩定

IF-GEO 的 VAR（0.0189）略高於 AutoGEO（0.0159），但 IF-GEO 的 WCP、DR、WTR 全面優於 AutoGEO。

**原因**：VAR 同時捕捉正面和負面的偏離。IF-GEO 的高 VAR 主要來自某些查詢增益特別大（上行波動），而非某些查詢大幅退步（下行波動）。DR 和 WCP 才能精確反映這個差異。

---

## 與既有指標的關係

這三個指標作為 [[citation-performance-metrics]] 的補充，專注於**跨查詢穩定性**這個維度，而 CR、VS、PAWC 等指標衡量的是**單查詢可見度**。

對多查詢 GEO 場景，兩類指標應並用：
- CR / PAWC / VS：告訴你平均可見度有多高
- WCP / DR / WTR：告訴你最脆弱的查詢安不安全
