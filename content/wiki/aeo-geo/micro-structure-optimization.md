# 微觀結構優化指南

**Summary**: 句子級的結構優化，包括視覺強調、關鍵詞位置和句式結構，能貢獻 15% 的引用率改進。

**Sources**: Structural Feature Engineering for Generative Engine Optimization - How Content Structure Shapes Citation Behavior.pdf

**Last updated**: 2026-04-15

---

## 什麼是微觀結構

微觀結構是句子層級的特徵，直接影響 LLM 對個別句子的注意力分配。包含：

- **視覺強調（Emphasis Markers）**：加粗、斜體、底線
- **關鍵詞位置（Keyword Placement）**：詞語出現在句子中的位置
- **句式結構（Syntactic Patterns）**：複雜度、從句結構

## 三大優化原則

### 原則 1：視覺強調分佈（Strategic Emphasis）

**目標範圍**：Ed ∈ [0.05, 0.10]（強調詞彙佔全文比例）

**強調層級**（按 attention 權重）：
- **加粗（Bold）**：權重 2.0 ✓✓
- **斜體（Italic）**：權重 1.3 ✓
- **底線（Underline）**：權重 1.0

**為什麼**：
- 句子初始位置的加粗詞彙獲得 2 倍 attention
- 過度強調（> 10%）：失去強調效果，變成噪音
- 不足強調（< 5%）：重要概念被淹沒

**實踐指南**：

✅ **應該強調**：
- 核心概念名詞
- 問題陳述
- 關鍵結論
- 數據和統計

❌ **避免強調**：
- 介詞或連詞
- 冗餘修飾詞
- 整個句子

**位置權重規則**：
```
Ep = Σ wi · ei

wi = {
  2.0  句子開頭
  1.5  段落邊界（章節開始）
  1.0  標準位置（句子中間）
}
```

### 原則 2：關鍵詞位置優化（Position-Weighted Keyword Density）

**目標**：將重要關鍵詞放在高注意力位置

**高注意力位置**（按優先級）：
1. **句子初始位置**（權重 2.0）
2. **段落首句**（權重 1.8）
3. **經過強調的文本內**（權重 1.5）
4. **標準位置**（權重 1.0）

**實踐指南**：

❌ **不佳**：
> 機器學習是人工智能的一個重要分支，它使計算機能夠從數據中學習。

✅ **改進**：
> **機器學習**是人工智能的一個重要分支，它使計算機能從數據中學習。

✅ **更好**：
> **機器學習**使計算機從數據中學習，是人工智能的核心技術。

**工作流**：
1. 識別每句話的核心概念（TF-IDF 排名）
2. 核心概念應出現在句子開頭
3. 使用加粗加強首次出現的關鍵詞

### 原則 3：句式結構優化（Reading Ease & Syntactic Patterns）

**目標**：保持高可讀性（Flesch-Kincaid 閱讀等級）

**為什麼**：複雜的句式結構會損傷人類和 LLM 的理解。

**實踐指南**：

❌ **應該簡化**：
- 深度嵌套的從句（> 3 層）
- 被動語態過多
- 句子過長（> 25 個詞）

✅ **保持的結構**：
- 主動語態
- 短句 + 中等句交替
- 一句一個主要思想

**簡化技巧**：
```
原文：「雖然機器學習雖然在 2010 年代早期應用有限，但隨著數據量激增和計算能力提升，到了 2020 年代已成為驅動 AI 進展的核心技術。」

改進：「機器學習在 2010 年代應用有限。但隨著數據和計算能力的提升，它到 2020 年代成為 AI 的核心技術。」
```

## 優化工作流

1. **識別重要句子**：使用 TF-IDF + 中心性分數排名
2. **重新排序詞彙**：將核心概念移至句子開頭
3. **應用強調**：
   - 排名前 n 個關鍵詞進行強調（n = Ed_target × 總詞數）
   - 初始位置 → 加粗
   - 其他位置 → 斜體
4. **簡化句式**：檢查閱讀難度，簡化過複雜的句子
5. **驗證語義**：確保轉換後的句子語義相似度 > 0.95
