## 什麼是 THT

THT（Through-Hole Technology，通孔技術）是將元件針腳穿過電路板通孔，再以焊錫固定的傳統焊接工藝。現代 GPU 的電源連接器（如 [[12v-2x6-connector]]）仍使用 THT 結構，因為通孔焊點在高電流環境下具有更高的機械強度與導電截面積。

---

## 關鍵概念：Barrel Fill（通孔填充率）

Barrel 指通孔內側的銅套管（copper sleeve）。焊接時，焊錫應充分填滿此套管，以確保針腳與 PCB 銅層的完整電氣接觸。

| 填充狀態 | 說明 |
|---|---|
| 理想（100%） | 焊錫從底部灌入，兩面均可見焊料圓弧（meniscus） |
| 可接受（≥75%） | IPC Class 2 最低要求，通孔深度填充四分之三以上 |
| 不足（<75%） | 不符合 IPC Class 2，有接觸電阻增加與熱應力疑慮 |

**注意**：barrel fill 無法從外觀判斷。頂面焊料量少，不代表內部通孔填充不足；有些製程刻意從底面單側焊接，頂面幾乎無可見焊冠，但通孔仍可能完全填滿。確認方式需 **X 光或截面顯微鏡**分析。

## 適用工業標準

| 標準 | 內容 |
|---|---|
| **IPC-A-610** | 電子組件焊點視覺驗收準則，定義 Class 1 / 2 / 3 等級 |
| **IPC-J-STD-001** | 焊接製程品質要求（材料、設備、製程控制） |

### IPC Class 等級說明

- **Class 1**：消費性一般電子產品，要求最低
- **Class 2**：工業及商業電子產品（含消費級 GPU），barrel fill ≥ 75%
- **Class 3**：航太、醫療、高可靠性要求，barrel fill ≥ 100%（兩面完整填充）

## 高電流連接器的特殊考量

一般 THT 焊點的主要功能是機械固定；但對於 GPU 的 12V 供電接頭，焊點同時承擔**高電流傳導**任務，因此有額外考量：

### GND 針腳 vs 供電針腳

| 針腳類型 | 冗餘程度 | 焊點不良的影響 |
|---|---|---|
| GND（接地）| **高**：PCIe 插槽另有並聯 GND 路徑，加上多條平行 GND 腳 | 個別針腳欠佳通常不影響功能 |
| 12V 供電 | **中**：有多條平行供電腳，但無外部並聯供電路徑 | 不均勻焊接可能導致電流分配不對稱，長期有熱應力與老化疑慮 |

### 主要失效機制（若 barrel fill 不足）

1. **接觸電阻增加**：有效導電截面積減少，電阻略升
2. **局部過熱**：高電流（尤其是 GPU 的瞬間負載峰值）在接觸面積不足處產生更多熱量
3. **熱機械疲勞**：反覆熱脹冷縮加速焊點微裂縫（hairline crack）
4. **電流不對稱**：單腳阻抗偏高迫使其他並聯腳承載更多電流

## 目視評估的限制

良好的目視評估可識別：
- **冷焊（cold joint）**：結晶狀、顆粒狀表面，表示焊接時溫度不足
- **未沾錫（non-wetting）**：錫料未附著，焊點呈球狀
- **凹陷過深的彎月面（excessive concave meniscus）**：可能暗示錫量不足

但目視**無法確認**：
- 通孔內部實際填充率
- 內部是否有空洞（void）
- 底面反面的焊接狀況（若從單側拍攝）

## 與 MSI Lightning Z 的關聯

[[lightning-z-igorslab-solder]] 的案例顯示：

- 疑似 barrel fill 不足的 12V 針腳，經電氣量測後接觸電阻與其他針腳相同
- 電流分配對稱，無局部過熱
- 推測焊點外觀問題可能僅為**小批量製程（選擇性焊接）導致的外觀差異**，而非實際通孔填充不足

此案例說明 IPC 標準的設計目的：允許製程公差，只要功能性指標達標即為可接受品。
