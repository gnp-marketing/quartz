# 導熱介面材料（TIM）

**Summary**：GPU 散熱系統中各位置使用的導熱介面材料（Thermal Interface Materials）種類、特性與選用邏輯，以 igorslab LIBS 元素分析 MSI RTX 5090 Lightning Z 為案例來源。

**Sources**：
- `igorslab - MSI GeForce RTX 5090 Lightning Z review – Lightning-fast and thirsty unicorn in battle against NVIDIA's clock speed barriers.docx`

**Last updated**：2026-04-24

---

## 什麼是 TIM

TIM（Thermal Interface Material，導熱介面材料）填充於熱源（GPU die、MOSFET、記憶體顆粒）與散熱器（水冷頭、導熱墊、背板）之間，消除表面微觀不平整造成的空氣間隙。空氣導熱率極低（約 0.025 W/mK），即使極薄的空氣層也會顯著惡化導熱效果。

---

## LIBS 分析方法

igorslab 使用 **Keyence VHX-7000 + 雷射深度鑽孔**（Laser Ablation / LIBS）技術，逐層移除表面材料後分析元素組成，可區分塗層、功能層與基材。這是非破壞性分析中最精確的成分識別方式之一，通常用於工業品質控制與材料研究。

---

## 各部件 TIM 分析（Lightning Z 實測）

### 1. GPU Die → 水冷頭：PTM Pad（相變導熱材料）

**LIBS 結果**：鋁（Al）、氧（O）、碳（C）、鋅（Zn）、氫（H），無矽（Si）

| 特性 | 說明 |
|---|---|
| 類型 | 無矽相變材料（Silicone-free Phase Change TIM）|
| 填充物 | 氧化鋁（Al₂O₃）+ 氧化鋅（ZnO）—— 提高有效導熱率 |
| 導熱率 | **>6.3 W/mK**（優於市售大多數散熱膏）|
| 室溫狀態 | 固態，便於組裝，不易位移 |
| 工作溫度 | 相變軟化，貼合 die 與冷頭微觀表面，Bond Line Thickness 極薄 |
| 長期穩定性 | **不會發生 Pump-Out 效應**；無矽避免低分子量矽氧烷擴散污染周邊介面 |

**為何不用傳統散熱膏**：大面積 die + 高循環熱應力環境下，傳統膏容易被擠出（pump-out），導致熱阻逐漸上升。PTM pad 固化後保持定位，維持長期穩定熱阻。

---

### 2. GDDR7 記憶體顆粒 → 水冷頭：高性能導熱墊

| 特性 | 說明 |
|---|---|
| 導熱率 | **9.12 W/mK** |
| 外觀質感 | 乾燥、油土狀，類似壓實的熱力膩子 |
| 機械特性 | 可適應不均勻表面，施壓後幾乎線性壓縮，不同層厚對應熱阻表現穩定 |
| 長期穩定性 | **不滲油（不 bleed）**，不釋放液態成分，維持尺寸穩定 |
| LIBS 組成 | 矽膠基（Si 為主）+ Al/Zn 氧化物填充 |

---

### 3. VRM MOSFET → 水冷頭：一般導熱墊

| 特性 | 說明 |
|---|---|
| 導熱率 | **3.3 W/mK**（中低端，功能足夠） |
| 材料 | 矽膠基聚合物，標準工業等級 |
| 功能重點 | 電氣絕緣 + 公差補償，非最高導熱效能 |
| LIBS 組成 | 碳（C）、氧（O）、矽（Si）、氫（H）為主 |

VRM MOSFET 的功率密度雖高，但面積較小；此處選用中等 TIM 屬合理工程取捨。

---

### 4. 背板 → PCB 背面：矽膠系導熱墊

| 特性 | 說明 |
|---|---|
| LIBS 組成 | PDMS 類矽膠基質 + 細分散 SiO₂ |
| 功能重點 | 提供 **電氣絕緣** + 機械公差補償 + 局部熱擴散 |
| 導熱率 | 偏低（類似 VRM 用途的 3.3 W/mK 等級）|
| 說明 | 背板的散熱功能為被動輔助，主要任務是機械強化與電氣保護 |

## 水冷頭與水冷排材質

這兩項不是 TIM，但屬於散熱路徑材料，igorslab 同樣進行了 LIBS 分析：

### 水冷頭（冷板）

- **材質：純銅，無鍍鎳**
- 最大導熱係數（~400 W/mK），無鍍層熱阻
- 缺點：開放式水路中對氧化較敏感；封閉 AIO 水路影響可忽略
- LIBS：100% 銅，無鎳、磷、錫等電鍍特徵元素

### 360mm 水冷排散熱片

- **材質：Al-Si 鋁合金，並非銅**
- 導熱係數低於銅，但靠大面積和細密鰭片補償
- 比銅輕、成本低、壁厚可做更薄
- 需要內部防腐塗層（鋁與水路中的銅形成電偶腐蝕風險）
- LIBS：鋁（Al）主導，含少量矽（Si），無銅（Cu）、無鎳（Ni）

## 背板材質補充

igorslab 特別指出：**Lightning Z 背板的碳纖紋路外觀僅為貼膜，並非真正碳纖維複合材料**。

實際材質：**Al-Si 鑄造合金（約 83% Al + 16-17% Si）**

| 特性 | Al-Si 合金說明 |
|---|---|
| 成型工藝 | 壓鑄（Die Casting），尺寸精度高、翹曲少 |
| 矽含量高的好處 | 降低熔點、改善流動性、增加硬度與耐磨性 |
| 導熱率 | 略低於純鋁，但足夠用作被動散熱擴散板 |
| 機械功能 | 防止長型 PCB 下彎（Sag）；作為 GPU 背面次要散熱擴散板 |

## TIM 選用原則總結

| 位置 | 優先考量 | 選用類型 |
|---|---|---|
| GPU Die（最高熱流密度） | 最低熱阻 + 長期穩定 | 無矽 PTM Pad（相變）|
| GDDR7 記憶體 | 高導熱 + 表面適應性 | 9.12 W/mK 乾燥型導熱墊 |
| VRM MOSFET | 電氣絕緣 + 公差補償 | 3.3 W/mK 矽膠系導熱墊 |
| PCB 背面/背板 | 電氣絕緣 + 機械緩衝 | 軟質矽膠系導熱墊 |
